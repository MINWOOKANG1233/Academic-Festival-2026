# 🤖 CareArm — AI Robot Arm Object Sorting System

2026 세종대학교 AI로봇학과 학술제 프로젝트

**발표일: 2026년 11월 27일(금)**

## 1. 프로젝트 소개

CareArm은 카메라와 AI 객체 인식 기술을 활용하여 생활용품을 자동으로 분류하는 6축 로봇팔 시스템입니다.

트레이에 놓인 생활용품 3종의 종류와 위치를 인식하고, 로봇팔이 해당 물체를 집어 종류별로 지정된 분류함에 옮기는 것을 목표로 합니다.

Windows 노트북에서 시스템을 먼저 구현하고, 최종적으로 NVIDIA Jetson 환경에서 독립적으로 구동하는 것을 목표로 합니다.

## 2. 시스템 동작 과정

1. 카메라로 트레이 촬영
2. YOLO를 이용한 객체 종류 및 위치 검출
3. OpenCV 기반 좌표 변환
4. 로봇팔의 집기 위치 및 이동 경로 결정
5. Python과 ESP32 시리얼 통신을 통한 로봇팔 제어
6. 물체를 종류별 분류함에 배치
7. 결과 기록 후 남은 물체 반복 인식

## 7. 실험 및 성능 평가

개발한 시스템의 성능은 다음 항목을 기준으로 평가합니다.

- **객체 검출 성능:** Precision, Recall, mAP50
- **좌표 변환 정확도:** 검증 지점 9곳에서 위치 오차 측정
- **분류 성공률:** 생활용품 3종 × 각 20회, 총 60회 이상 시도
- **처리 시간:** 객체 검출부터 분류 완료까지 소요 시간
- **실패 분석:** 검출, 좌표, 집기, 이동, 배치, 통신 오류 구분

분류 성공은 사람의 개입 없이 올바른 물체를 지정된 분류함에 옮긴 경우로 정의합니다.
