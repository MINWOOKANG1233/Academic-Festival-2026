# 2026-11-16 YOLO 인식·집기 연결

## 구현
- robot/yolo_pick.py: 기존 학습 모델로 원본 JPEG를 검출하고 클래스·관찰 자세의 중심 좌표를 기존 집기에 전달.
- start_yolo_pick.cmd: 로봇 포트를 열지 않는 인식 확인.
- start_yolo_grab.cmd: 별도 카메라·로봇 포트와 INIT/PICK/GRAB/RELEASE 확인을 거치는 집기 실행.
- setup_yolo.cmd, robot/requirements-yolo.txt: 선택적 YOLO 설치. 기존 조작 창 의존성은 유지.
- vision/camera_red_block.py: 카메라·배경 초기화 후 USB 모드 전환, 진단 메시지 추가.
- vision/camera_diagnostic_ide.py: IDE 영상·오류 확인용, USB 전송 비활성.

## 확인
- 장비 없는 테스트 39개 통과. 기존 테스트 31개 + YOLO 선택·안정 조건·단계 확인 8개.
- 실제 카메라 포트 COM5에서 사용자 검출 시험.
- 큐브: 확신도 0.72~0.74, 격자 약 (117.6,38.1) mm, 연속 3장 안정 결과 확인.
- 휴지심: 확신도 0.89~0.90의 검출 출력 확인. 첫 공유 실행은 범위 제한·안정 샘플 부족으로 중단. 이후 사용자가 세 물체 모두 동작 확인했다고 보고.
- 이클립스 통: 확신도 약 0.83, 격자 (106.2~106.5,81.3~83.1) mm, 연속 3장 확인.

## 남은 검증
- 새 YOLO 연결 경로의 실물 집기는 아직 미검증. 기존 물체별 사진 정렬·집기 동작을 재사용.
- H는 11월 4일 평면 보정값. 상자 중심을 평면에 투영하므로 물체 높이·카메라 위치 변화의 실제 오차를 확인해야 함.
- 원래 위치 내려놓기만 포함. 분류 통 이동은 미구현.
- 오류/취소 시 자동 복귀하지 않음. 로봇 포트 번호는 실제 연결 상태에서 확인 필요.
